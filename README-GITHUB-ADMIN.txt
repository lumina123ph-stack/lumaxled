LUMAX LED TRADING - GitHub Admin

Files: index.html, admin.html, assests/, data/
Admin saves products and images directly to GitHub via the Contents API.
Use a fine-grained GitHub token restricted to this repository with Contents: Read and write.
Never publish the token in the repository or send it to anyone.

For GitHub Pages, publish the main branch from the repository root. GitHub Pages automatically publishes changes pushed to the publishing branch.
